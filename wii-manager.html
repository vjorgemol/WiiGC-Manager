Scripts de integración

Esta GUI genera y ejecuta comandos wit / wwt vía zenity o directamente en bash. Para integrarlo con tu escritorio, usa el lanzador incluido.

Referencia de comandos wit / wwt
wwt LIST -p /ruta/wbfs — listar juegos en WBFS
wwt ADD -p /ruta/wbfs juego.iso — añadir ISO al WBFS
wwt EXTRACT -p /ruta/wbfs ID --dest /dst/ — extraer a ISO
wwt REMOVE -p /ruta/wbfs ID — eliminar juego
wwt VERIFY -p /ruta/wbfs — verificar todos los juegos
wit COPY src.iso dst.wbfs — copiar / convertir
wit VERIFY juego.iso — verificar integridad
wit LIST juego.iso — info del juego
wwt --auto LIST — detectar WBFS automáticamente

Preparar y Formatear Unidad (Wii & GameCube)

Prepara automáticamente cualquier pendrive USB, disco externo o tarjeta SD para su uso con WiiFlow, USB Loader GX y Nintendont. Incluye protección contra formateo accidental del sistema operativo.

1 Seleccionar unidad o partición
Elige la unidad USB o tarjeta SD que deseas preparar:
Cargando dispositivos de almacenamiento…
2 Sistema de archivos y estructura
FAT32 — Recomendado (Wii + GameCube / WiiFlow / Nintendont) Estándar Universal
Formatea la partición en FAT32 con tamaño de clúster de 32 KB (óptimo para evitar cuelgues de audio y vídeo en Nintendont). Es el formato compatible simultáneamente con juegos de Wii (archivos .wbfs) y GameCube (.iso).
WBFS Puro (Partición dedicada clásica con wwt)
Partición sin sistema de archivos tradicional gestionada directamente con herramientas wwt. Solo compatible con juegos de Wii (no admite GameCube).
Necesita conexión a Internet y requiere la opción "Crear carpetas" activada.
3 Ejecutar formateo

⚠️ Advertencia: El formateo eliminará todos los archivos presentes en la partición o unidad seleccionada. Asegúrate de haber seleccionado la unidad correcta antes de continuar.
